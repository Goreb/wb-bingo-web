# Warehouse wordmarks

Downloaded 26.10.2026 for operator identification in local warehouse cards.
Original artwork is retained; CSS preserves the original colours on the existing dark badge. These are not claimed to be official current dark-mode editions.
Logos remain trademarks of their respective owners; no affiliation is implied.

- `ozon.svg`: Ozon wordmark, source linked by
  https://commons.wikimedia.org/wiki/File:Ozon_logo_clear.svg :
  https://static.tildacdn.com/tild3438-3737-4138-b830-393232666130/logo-logo-ozon-blue.svg
  Commons describes the simple text/geometric logo as PD-textlogo.
- `wildberries.svg`: 2023 wordmark, credited to Wildberries, Letterhead Studio,
  Yuri Gordon; source wildberries.ru, via
  https://commons.wikimedia.org/wiki/File:Wildberries_2023_Pink.svg
  https://upload.wikimedia.org/wikipedia/commons/4/41/Wildberries_2023_Pink.svg
  Commons describes the simple text logo as PD-textlogo.

Other operators retain text labels. No external requests are needed at runtime.
